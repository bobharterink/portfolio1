Studio Harterink

HTML CSS JS THREE.JS R3F STRIPE VITE

Context

Studio Harterink is ontstaan vanuit een reeks modulaire vazen die ik zelf heb ontworpen en gemaakt. De vazen passen door de brievenbus en worden door de gebruiker zelf geassembleerd, zodat het voelt alsof je het object ook écht zelf hebt gemaakt. Diezelfde ervaring wilde ik vertalen naar een digitale omgeving. Het doel van de website was niet alleen het tonen van producten, maar het nabootsen van het fysieke assemblageproces in een interactieve webervaring.

Studio Harterink

HTML CSS JS THREE.JS R3F STRIPE

Concept & interactie

Tijdens het scrollen wordt de vaas digitaal opgebouwd vanuit een 3d omgeving. Elk onderdeel verschijnt door het scrollen hierdoor krijgt de gebruiker het gevoel alsof die het object zelf samen stelt. . Scrollen wordt zo een essentieel onderdeel van de beleving, niet enkel een navigatie-actie. Wanneer je de andere versie’s aanclickt gaat het scroll event verder met de nieuwe vaas. Je scrollt door het hele process. De vaas heb ik ook uit andere materiaal gemaakt, en wordt gebruikt als lamp, Hiervoor heb ik een andere pagina aangemaakt, om meer het gevoel van luxe materiaal te voelen. Hier maak ik gebruik van veel dezelfde technieken.

Technische uitwerking

  • Opzetten van een custom scroll-gedreven interactie
  • Integratie van 3D-objecten met Three.js
  • Performance-bewuste rendering van 3D content in de browser
  • Volledig custom frontend zonder frameworks
  • Focus op responsive gedrag en vloeiende animaties
  • Intergratie van Stripe op producten te verkopen

Iteratie

lamp versie: meer detail, verfijnde animaties en extra objecten

Waarom dit project?

Dit project laat zien hoe ik:

  • abstracte concepten vertaal naar concrete interacties
  • design en techniek combineer in één geheel
  • verder denk dan een standaard "productpagina"
Fizzi

Fizzi

NEXT.JS JS GSAP TAILWIND THREE.JS R3F PRISMIC CMS

Context

fizzi is een professioneel opgebouwde website waarin ik onderzocht aan de hand van een tutorial hoe interactieve frontend samen met next.js, gsap en three/r3f kan samengaan met dynamische content vanuit een CMS. Het uitgangspunt was om een visueel rijke website te bouwen die niet hard-gecodeerd is, maar waarbij content eenvoudig aangepast kan worden door de gebruiker.

Fizzi

NEXT.JS JS GSAP THREE.JS R3F PRISMIC CMS

Concept & interactie

Bij het laden van de site zakken de blikjes langzaam naar beneden en bewegen ze zich speels door de hele website. Tijdens het scrollen worden de blikjes geleidelijk naar elkaar toe gebracht, terwijl stap voor stap informatie over de frisdrank wordt onthuld. Daarnaast zorgen click-events ervoor dat de gebruiker actief in interactie treedt met de 3D-modellen, waardoor de ervaring niet alleen visueel, maar ook tactiel en ontdekkend aanvoelt.

Technische uitwerking

  • Opzet van een component-gedreven frontend in Next.js
  • Koppeling met Prismic CMS voor dynamische content
  • Gebruik van GSAP voor scroll- en micro-interacties
  • Integratie van Three.js voor 3D-objecten binnen de layout

Waarom dit project?

Dit project toont mijn manier van werken in een realistische frontend-omgeving:

  • werken met een moderne stack
  • rekening houden met schaalbaarheid en onderhoud
  • visuele interacties inzetten zonder het functionele aspect te verliezen
FridgePick

FridgePick

NEXT.JS MONGO DB API ROUTES GSAP

Context

Fridgepick vertrekt vanuit een herkenbaar probleem: je hebt nog ingrediënten in huis, maar geen idee wat je ermee kunt koken. De webapp helpt gebruikers door ingrediënten die nog in de koelkast liggen te koppelen aan passende recepten. De focus lag op het ontwikkelen van een toegankelijke en gebruiksvriendelijke applicatie waarin inspiratie centraal staat.

FridgePick

NEXT.JS MONGO DB API ROUTES GSAP

Concept & interactie

Op de website kunnen gebruikers in de header ingrediënten invoeren. Op basis daarvan worden per ingrediënt twee maaltijden voorgesteld die ermee te bereiden zijn. Deze suggesties worden gegenereerd via een API. Als vervolgstap kunnen gebruikers een account aanmaken om recepten op te slaan en een Pro-abonnement af te sluiten. Hiermee krijgen ze toegang tot een uitgebreider aanbod aan gerechten. De rest van de website focust op bewustwording rond voedselverspilling en laat zien hoe Fridgepick helpt om dit tegen te gaan.

Technische uitwerking

  • Opzetten van een custom scroll-gedreven interactie
  • Integratie van 3D-objecten met Three.js
  • Performance-bewuste rendering van 3D content in de browser
  • Volledig custom frontend zonder frameworks
  • Focus op responsive gedrag en vloeiende animaties
