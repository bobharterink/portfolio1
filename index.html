HTML CSS JS THREE.JS R3F STRIPE

Concept & interactie

Tijdens het scrollen wordt de vaas digitaal opgebouwd vanuit een 3d omgeving. Elk onderdeel verschijnt door het scrollen hierdoor krijgt de gebruiker het gevoel alsof die het object zelf samen stelt. . Scrollen wordt zo een essentieel onderdeel van de beleving, niet enkel een navigatie-actie. Wanneer je de andere versie’s aanclickt gaat het scroll event verder met de nieuwe vaas. Je scrollt door het hele process. De vaas heb ik ook uit andere materiaal gemaakt, en wordt gebruikt als lamp, Hiervoor heb ik een andere pagina aangemaakt, om meer het gevoel van luxe materiaal te voelen. Hier maak ik gebruik van veel dezelfde technieken.

Technische uitwerking

  • Opzetten van een custom scroll-gedreven interactie
  • Integratie van 3D-objecten met Three.js
  • Performance-bewuste rendering van 3D content in de browser
  • Volledig custom frontend zonder frameworks
  • Focus op responsive gedrag en vloeiende animaties
  • Intergratie van Stripe op producten te verkopen

Iteratie

lamp versie: meer detail, verfijnde animaties en extra objecten

Waarom dit project?

Dit project laat zien hoe ik:

  • abstracte concepten vertaal naar concrete interacties
  • design en techniek combineer in één geheel
  • verder denk dan een standaard "productpagina"

Fizzi

NEXT.JS JS GSAP THREE.JS R3F PRISMIC CMS

Context

fizzi is een professioneel opgebouwde website waarin ik onderzocht aan de hand van een tutorial hoe interactieve frontend samen met next.js, gsap en three/r3f kan samengaan met dynamische content vanuit een CMS. Het uitgangspunt was om een visueel rijke website te bouwen die niet hard-gecodeerd is, maar waarbij content eenvoudig aangepast kan worden door de gebruiker.

Concept & interactie

Bij het laden van de website zakken de blikjes langzaam naar beneden en bewegen ze door de hele site. Met behulp van scrolleffecten worden de blikjes geleidelijk samengebracht, terwijl er informatie over de frisdrank wordt verteld. Daarnaast zorgen click-events ervoor dat de gebruiker interactie heeft met de 3D-modellen en het verschillende aanbod kan ontdekken.

Technische uitwerking

  • Opzet van een component-gedreven frontend in Next.js
  • Koppeling met Prismic CMS voor dynamische content
  • Gebruik van GSAP voor scroll- en micro-interacties
  • Integratie van Three.js voor 3D-objecten binnen de layout

Waarom dit project?

Dit project toont mijn manier van werken in een realistische frontend-omgeving:

  • werken met een moderne stack
  • rekening houden met schaalbaarheid en onderhoud
  • visuele interacties inzetten zonder het functionele aspect te verliezen

FridgePick

NEXT.JS MONGO DB API ROUTES GSAP

Context

Fridgepick vertrekt vanuit een herkenbaar probleem: je hebt nog ingrediënten in huis, maar geen idee wat je ermee kunt koken. De webapp helpt gebruikers door ingrediënten die nog in de koelkast liggen te koppelen aan passende recepten. De focus lag op het ontwikkelen van een toegankelijke en gebruiksvriendelijke applicatie waarin inspiratie centraal staat.

Concept & interactie

Op de website kun je in de header ingrediënten toevoegen. Op basis van deze ingrediënten krijg je vervolgens twee maaltijden te zien die je ermee kunt bereiden. Dit gebeurt via een API die de recepten genereert. Als vervolgfunctie zou de gebruiker kunnen inloggen om recepten op te slaan en een ‘pro’-abonnement af te sluiten, waarmee meer gerechten beschikbaar komen. De rest van de website staat in het teken van voedselverspilling en laat zien hoe deze webapp helpt om verspilling tegen te gaan.

Technische uitwerking

  • Opzet van de frontend in Next.js
  • Gebruik van API routes voor communicatie tussen frontend en database
  • Focus op duidelijke UI-flows en snelle interactie
  • 'Pro' modus voor meer gerechten

Waarom dit project?

Fridgepick was mijn eerste project waarin ik bewust full-stack features combineerde met een sterke frontend focus. Het project markeert mijn overgang van puur frontend werk naar het begrijpen en bouwen van complete webapplicaties, zonder de gebruikservaring uit het oog te verliezen.

Dirk Nielandt

HTML CSS JS CRAFT CMS

Context

Dirk Nielandt is een kinderboekenschrijver die zijn werk online zichtbaar wilde maken. Naast een overzicht van zijn boeken was er behoefte aan betere vindbaarheid, duidelijke informatie per boek en een laagdrempelig contactpunt. Het doel was een eenvoudige, onderhoudbare website die zelfstandig beheerd kan worden door de auteur.

Concept & interactie

De website van Dirk Nielandt is vormgegeven in een stijl die past bij zijn werk als kinderboekenschrijver. De uitstraling sluit aan bij de doelgroep en de sfeer van zijn boeken. Voor de schrijver is het eenvoudig om boeken toe te voegen, te verwijderen of extra onder de aandacht te brengen, bijvoorbeeld wanneer een boek een prijs wint of net is uitgebracht.
Craft CMS kan hij gemakkelijk tags toekennen om te bepalen waar een boek op de website wordt weergegeven en welke informatie daarbij hoort. De website is bewust eenvoudig gehouden, maar bevat subtiele, speelse effecten, zoals hover-animaties bij bekroonde boeken en een bewegend oog in het logo dat elke tien seconden tot leven komt.

Technische uitwerking

  • Opzet van een custom frontend in HTML, CSS en JavaScript
  • Implementatie van Craft CMS voor contentbeheer
  • Opzetten van gestructureerde contenttypes voor boeken
  • Mogelijkheid om per boek:
    • leeftijdscategorie toe te kennen
    • plaatsing op specifieke pagina’s te bepalen
    • een optionele “sticker” met eigen tekst toe te voegen
  • Focus op duidelijke contenthiërarchie en onderhoudbaarheid

Dit project laat zien hoe ik:

  • abstracte concepten vertaal naar concrete interacties
  • design en techniek combineer in één geheel
  • verder denk dan een standaard "productpagina"
