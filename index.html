Door het oog van de Maker

HTML CSS JS PY S3 FIRESTORE NODEBOX

Concept & interactie

Het project vertrekt vanuit mijn fascinatie voor moiré-patronen, die ik wil delen met de bezoeker. Via de website maken bezoekers een wazige foto met hun camera, waarop cirkels, vierkanten en lijnen reageren op lichte en donkere zones. Met sliders kan het ontwerp volledig worden aangepast: vorm, intensiteit en kleur. Bij het printen worden de kleurlagen opgesplitst en één voor één naar de AxiDraw gestuurd, waarna de bezoeker telkens de juiste kleur plaatst. Zo ontstaat een uniek, zelfgemaakt moiré-postkaartje.

Technische uitwerking

  • Web-based interface gebouwd met HTML, CSS en JavaScript
  • Gebruik van de device camera om een wazige foto te maken
  • Analyse van licht- en donkerwaarden in de afbeelding
  • Realtime aanpasbaar ontwerp via sliders (vorm, intensiteit, dichtheid)
  • Automatische opsplitsing van het ontwerp in kleur-lagen
  • Elke kleurlaag wordt sequentieel naar de AxiDraw gestuurd
  • Handmatige kleurwissel door de gebruiker tijdens het plotten
